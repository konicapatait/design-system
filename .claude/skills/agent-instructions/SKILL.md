name: agent-instructions
description: Maintain one shared set of agent instructions/skills for Claude Code and GitHub Copilot with no duplication. Use when asked to update CLAUDE.md or copilot-instructions, add or change a shared skill / prompt / path-scoped rule, keep agent docs in sync across tools, add support for another AI agent, or wire the sync check into CI.
---

All paths are relative to the repo root (`design-system/`).

One source of truth, generated fan-out. Humans edit **only**:

| Source | Consumed by | How |
| --- | --- | --- |
| `AGENTS.md` | Claude Code | `CLAUDE.md` has `@AGENTS.md` (native import — nothing generated) |
| `AGENTS.md` | GitHub Copilot | `.github/copilot-instructions.md` is generated verbatim (Copilot has no include) |
| `AGENTS.md` sections tagged `<!-- copilot:applyTo=<glob> -->` | Copilot (VS Code) | `.github/instructions/<slug>.instructions.md`, path-scoped, generated |
| `.claude/skills/<name>/SKILL.md` | Claude Code | native |
| `.claude/skills/<name>/SKILL.md` | Copilot (VS Code) | `.github/prompts/<name>.prompt.md`, generated |

The generator/driver is **`scripts/sync-agent-instructions.mjs`** (Node ≥ 20, no
deps). Every generated file starts with a `GENERATED by …` banner and is safe to
delete — the driver recreates it.

## Run (agent path)

Regenerate every Copilot file from the sources:

```bash
node scripts/sync-agent-instructions.mjs
```

```
created  .github/copilot-instructions.md
created  .github/instructions/working-in-libs-tokens.instructions.md
...
done (5 changes)
```

Verify nothing is stale (this is what CI runs; exits 1 on drift):

```bash
node scripts/sync-agent-instructions.mjs --check
# -> "agent instructions are in sync", exit 0
```

Same two commands are wired as npm scripts:

```bash
npm run sync:agents
npm run check:agents
```

## Editing workflow

1. **Project guidance** → edit `AGENTS.md`. To make a section also become a
   path-scoped Copilot rule, put a marker on its own line under the heading:

   ```markdown
   ## Working in `libs/tokens`
   <!-- copilot:applyTo=libs/tokens/** -->
   ```

   Multiple globs: `<!-- copilot:applyTo=libs/a/**,libs/b/** -->`.

2. **A skill** → create/edit `.claude/skills/<name>/SKILL.md` with `name:` +
   `description:` frontmatter. It becomes `.github/prompts/<name>.prompt.md`
   (`mode: agent`) on the next sync.

3. `npm run sync:agents`, then commit the sources **and** the regenerated
   `.github/` files together.

CI already runs `npm run check:agents` (step in `.github/workflows/ci.yml`), so a
PR that edits a source without re-syncing fails. `.vscode/settings.json` enables
the Copilot prompt + instruction files for contributors.

## Adding another agent tool

Add one emit block to `scripts/sync-agent-instructions.mjs` that writes that
tool's format from the already-parsed `sections` / skills. Keep `AGENTS.md` the
source; do not add a second hand-maintained doc.

## Gotchas

- **Copilot has no `@import`.** `.github/copilot-instructions.md` must be a full
  copy — hence the generator. Don't replace it with a pointer.
- **`applyTo` is a VS Code Copilot feature.** The Copilot *coding agent* (cloud)
  reads `.github/copilot-instructions.md` (and `AGENTS.md`) but not
  `.github/instructions/*`. Anything that must reach the cloud agent belongs in
  an un-marked `AGENTS.md` section too.
- **`.prompt.md` files need `chat.promptFiles` enabled** in VS Code (default on
  in current builds). They are invoked as `/<name>` in Copilot Chat.
- **Don't hand-edit generated files.** `--check` will flag them as `stale` and CI
  fails. Edit the source, re-sync.
- **Orphan cleanup only touches files with the banner.** A hand-written
  `.github/instructions/*.instructions.md` is left alone.
- **`CLAUDE.md` is static** — `@AGENTS.md` + a short Claude-only note. It is not
  generated and needs no sync.

## Troubleshooting

- **`AGENTS.md not found at repo root`**: run from the repo root, or the file was
  moved. The driver resolves paths from its own location (`scripts/..`).
- **`--check` says `stale` right after a sync**: you edited a generated file by
  hand. Re-run `npm run sync:agents` and commit.
- **A new section didn't produce an instructions file**: the marker must be on
  its **own line**, exact form `<!-- copilot:applyTo=<glob> -->`, directly under
  a `##`/`###` heading.
